## 元ファイルとの重要な相違
- IDは再構築用の `REC-*` 名前空間であり、元の固有IDを引き継がない。
- 既知の `COL_013_watercolor` は元報告書に表示されたレシピの説明用例に過ぎず、辞書レコードと検証できないため、元IDとして再利用していない。
- `Evidence_Level` と `Source_URL` は直接のモデル検証と区別した。個々のモデルで画像生成した実測データはない。
- レシピ・相性・優先度は構造と件数を再設計したもので、元の割当と異なり得る。
- `validation_matrix.csv` の486行は実行済みではない。全件 `not_run`。
