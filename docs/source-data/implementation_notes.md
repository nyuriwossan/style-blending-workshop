# 実装メモ（再構築版・旧成果物ではない）

## 真正性
このフォルダの辞書329件、競合53件、プリセット36件、検証486行はこの会話で新しく作成したもの。件数は元報告書の集計と一致させたが、元ID・タグの選定・説明・個々の優先度・モデル別評価との完全一致は確認できない。

## データと互換性
- 元の `style_tags.json` と保存済みレシピはこのデータへIDでそのまま移行してはならない。新IDは `REC-*` とする。
- 過去レシピを取り込む場合はユーザー確認付きマッピング画面を用意する。`Original_ID` は全件 `null` である。
- 辞書は意味概念と生成用文字列を別の項目として保持し、モデルごとのレンダラーは `model_output_rules.json` と分離する。
- `Evidence_Level`, モデル別状況, `Validation_Status` をUI上でも表示し、未実測の効果を保証しない。

## MVPの推奨範囲
9カテゴリのうち `MVP_Core=true` の72候補。プリセットは `items[].tagId` と `strength` で展開。各項目はOFF=0、それ以外1.0を標準とする。曖昧な衝突は基本的に警告で扱う。

## 変換と回帰テスト
- SDXL は `(tag:weight)` の一般形、モデルへの実効性は個別未検証。weightはデフォルト1.5を上限とする。
- Tsubaki.2/3 は自然言語段階変換を **UX上の実験案** とし、数値ウェイトとの同等性を宣言しない。ネガティブプロンプトは生成しない。
- NovelAI V4/V4.5/V5 は `weight::tag ::` 型、V3は括弧反復の近似。
- 強度0は出力から除外、1.0は余分な装飾を付けない。保存時は不変IDと強度を保持。
- 競合は情報提示を原則とし、無断削除しない。未知ID・廃止IDを含む保存データは破棄せず警告と共に部分読み込み。
- JSONのスキーマ検証・importサイズ制限・HTMLエスケープ・入力検査・バックアップ復元のテストを必須とする。
- 複数seed・人物/風景/静物で効果検証してから「確認済み」評価を付ける。
